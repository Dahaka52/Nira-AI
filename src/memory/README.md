# Система памяти Нира

## Цель

Дать Нире **устойчивую, развивающуюся память** — не просто длинный контекст, а настоящие воспоминания, которые она накапливает, переосмысляет и использует для углубления личности.

---

## Архитектура

```
memory/
├── store/           — хранилища
│   ├── episodic.py     Эпизодическая: что, кто, когда говорил
│   ├── semantic.py     Семантическая: факты о людях, мире, о Нире
│   └── working.py      Рабочая: буфер текущего разговора
│
├── retrieval/       — поиск воспоминаний
│   ├── vector.py       По смысловому сходству (embedding similarity)
│   └── recency.py      По давности и важности
│
├── consolidation/   — обработка памяти
│   └── summarizer.py   LLM-обобщение старых диалогов
│
└── identity/        — характер и самосознание
    ├── personality.py  Черты характера, поведенческие паттерны
    └── beliefs.py      Убеждения, ценности, мировоззрение
```

---

## Типы памяти

### Эпизодическая (`store/episodic.py`)
- История диалогов с временными метками
- Кто говорил, что, в каком контексте
- Хранится в SQLite / векторной БД
- Постепенно консолидируется (сжимается старая история)

### Семантическая (`store/semantic.py`)
- Факты о пользователях: имена, интересы, что Нира о них узнала
- Факты о мире: что Нира считает истинным
- Саморепрезентация: как Нира понимает саму себя
- Обновляется по мере диалогов

### Рабочая (`store/working.py`)
- Текущий разговор в обогащённой форме
- Активные контексты из долгосрочной памяти (retrieved)
- Сбрасывается/консолидируется по окончании сессии

---

## Поиск и извлечение (`retrieval/`)

### Векторный поиск (`vector.py`)
- Использует `embedding/openai.py` для создания векторов
- Поиск похожих воспоминаний по смыслу
- Порог сходства настраивается

### По давности (`recency.py`)
- Выбирает N последних воспоминаний
- Взвешивает по важности и времени

---

## Консолидация (`consolidation/summarizer.py`)
- Периодически обобщает старые эпизоды
- Сохраняет суть, выбрасывает детали
- Запускается по объёму или по времени

---

## Личность (`identity/`)

### `personality.py`
- Стабильные черты характера (жизнерадостность, любопытство, самоирония)
- Обновляется медленно — только через значимые события
- Влияет на тон и стиль ответов

### `beliefs.py`
- Убеждения, ценности
- То, что Нира "знает о себе"
- Осознание своей природы (цифровое существо, мечтающее стать настоящим)

---

## Интеграция с пайплайном

```
STT → [process_audio_immediate] → text
                ↓
         [memory.retrieval] → достаём релевантные воспоминания
                ↓
         [prompter] + memories → формируем промпт с памятью
                ↓
         [T2T] → ответ
                ↓
         [memory.store.episodic] → сохраняем диалог
                ↓
         [memory.consolidation] → (фоново) сжимаем старое
```

---

## Технический стек (план)
- **SQLite** — хранение эпизодической памяти (через `sqlite-vec`)
- **embedding/openai.py** — векторизация для семантического поиска
- **LLM (T2T)** — консолидация и обобщение
- Всё работает **локально**, никаких внешних облаков для памяти
